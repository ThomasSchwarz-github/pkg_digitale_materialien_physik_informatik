Aufbau einer Klasse

Schlüsselwort class, Klassenkopf, geschweifte Klammern und die feste Reihenfolge: Attribute, Konstruktor, Methoden.

Worum geht es?

Ein Java-Programm besteht aus Klassen. Eine Klasse ist der Bauplan für Objekte: Sie legt fest, welche Eigenschaften (Attribute) jedes Objekt hat und was jedes Objekt tun kann (Methoden). Jede Klasse steht in einer eigenen Datei, die genauso heißt wie die Klasse, z. B. Auto.java. In BlueJ legst du eine Klasse mit dem Knopf „Neue Klasse …“ an.

Der Kopf der Klasse

public class Auto
  • public schreiben wir vorerst immer davor.
  • class ist das Schlüsselwort, das eine Klasse einleitet.
  • Danach folgt der Name der Klasse. Er beginnt mit einem Großbuchstaben und enthält keine Leerzeichen und keine Umlaute. Meist ist er ein Nomen im Singular: Auto, nicht Autos, denn die Klasse beschreibt, wie ein Auto aussieht.

Das Grundgerüst

Nach dem Kopf folgen geschweifte Klammern { }. Alles, was zur Klasse gehört, steht dazwischen, und zwar immer in derselben Reihenfolge:

public class Auto
{
    // 1. Attribute

    // 2. Konstruktor

    // 3. Methoden
}
  1. Attribute: die Eigenschaften, die sich jedes Objekt merkt. → Attribute und Datentypen
  2. Konstruktor: legt fest, mit welchen Startwerten ein neues Objekt beginnt (siehe unten).
  3. Methoden: das, was jedes Objekt tun kann. → Einfache Methoden

Die Zeilen mit // sind Kommentare. Sie sind nur für Menschen gedacht; der Computer überliest sie.

Ein vollständiges Beispiel

So sieht eine kleine, aber vollständige Klasse aus, mit einem Attribut, dem Konstruktor und einer Methode:

public class Auto
{
    private int kilometerstand;

    public Auto()
    {
        this.kilometerstand = 0;
    }

    public void fahre100km()
    {
        this.kilometerstand = this.kilometerstand + 100;
    }
}
ZeilenBedeutung
1–2, 14Kopf der Klasse und die geschweiften Klammern, die alles umschließen
3ein Attribut: kilometerstand vom Datentyp int
5–8der Konstruktor: Ein neues Auto beginnt mit dem Kilometerstand 0.
10–13eine Methode: Das Auto fährt 100 km, der Kilometerstand steigt um 100.

Der Konstruktor

    public Auto()
    {
        this.kilometerstand = 0;
    }
  • Der Konstruktor heißt genau wie die Klasse, mit großem Anfangsbuchstaben.
  • Vor dem Namen steht nur public, kein Datentyp und kein void.
  • Er wird automatisch ausgeführt, wenn ein neues Objekt hergestellt wird, in BlueJ also beim Rechtsklick auf die Klasse und new Auto().
  • Darin bekommt jedes Attribut seinen Startwert. this.kilometerstand bedeutet: der Kilometerstand dieses Objekts.

Regeln auf einen Blick

  • Kopf: public class Name, der Name beginnt groß.
  • Zu jeder öffnenden Klammer { gehört eine schließende }.
  • Reihenfolge im Rumpf: erst die Attribute, dann der Konstruktor, dann die Methoden.
  • Jede Anweisung endet mit einem Semikolon ;. Nach Kopfzeilen, auf die eine { folgt, steht kein Semikolon.
  • Java unterscheidet Groß- und Kleinschreibung: Auto und auto sind verschiedene Namen.
  • Was zwischen { und } steht, wird um vier Leerzeichen eingerückt. Das macht den Code lesbar, auch wenn der Computer es nicht braucht.
