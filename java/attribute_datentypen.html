Attribute und Datentypen

Wie ein Attribut deklariert wird, welche Datentypen es zunächst gibt und wie Attribute ihre Startwerte bekommen.

Was ist ein Attribut?

Ein Attribut ist eine Eigenschaft, die sich jedes Objekt einer Klasse merkt, zum Beispiel der Kilometerstand eines Autos. Die Klasse legt fest, welche Attribute es gibt. Jedes Objekt hat dafür seine eigenen Werte, die Attributwerte.

Ein Attribut deklarieren

Attribute stehen ganz oben in der Klasse, vor dem Konstruktor. Jedes Attribut bekommt eine eigene Zeile nach diesem Muster:

    private int kilometerstand;
TeilBedeutung
privateder Zugriffsmodifikator. Was er genau bedeutet, lernst du später. Vorerst gilt: Vor jedes Attribut schreiben wir private.
intder Datentyp: welche Art von Wert das Attribut speichert (siehe unten)
kilometerstandder Name des Attributs
;das Semikolon beendet die Deklaration

Das Deklarieren heißt: Man kündigt an, dass es dieses Attribut gibt. Einen Wert bekommt es erst im Konstruktor (siehe unten).

Die ersten Datentypen

DatentypspeichertWerte im CodeBeispiel
intganze Zahlen (positiv und negativ), mit denen man rechnen kann 0, 2019, -3private int baujahr;
StringZeichenketten, also Texte in Anführungszeichen: "VW", "GL-AB 123"private String marke;
booleanWahrheitswerte: wahr oder falsch nur true oder falseprivate boolean motorLaeuft;

int und boolean sind elementare Datentypen und werden kleingeschrieben. String wird großgeschrieben, weil es genau genommen eine Klasse ist. Du benutzt es aber genauso wie die anderen Datentypen.

So entscheidest du: Lässt sich die Eigenschaft mit Ja oder Nein beantworten? → boolean. Ist sie eine ganze Zahl, mit der man rechnen will? → int. Sonst → String. Ein Kennzeichen enthält zwar Ziffern, ist aber ein Text.

Namen für Attribute

  • Der Name beginnt mit einem Kleinbuchstaben und enthält keine Leerzeichen und keine Umlaute.
  • Bei mehreren Wörtern beginnt jedes weitere Wort groß: motorLaeuft, anzahlTueren.
  • Der Name sagt genau, was gespeichert wird: marke für "Porsche" ist besser als ein unklares name.

Startwerte im Konstruktor

Im Konstruktor bekommt jedes Attribut seinen Startwert. Das geschieht mit einer Zuweisung:

public class Auto
{
    private String marke;
    private int kilometerstand;
    private boolean motorLaeuft;

    public Auto()
    {
        this.marke = "VW";
        this.kilometerstand = 0;
        this.motorLaeuft = false;
    }
}
  • Das Gleichheitszeichen = heißt in Java „bekommt den Wert“: this.kilometerstand = 0; bedeutet „der Kilometerstand dieses Objekts bekommt den Wert 0“.
  • Der Wert muss zum Datentyp passen: Text in Anführungszeichen, Zahlen ohne, Wahrheitswerte als true oder false.
  • Bekommt ein Attribut keinen Startwert, hat es automatisch einen Standardwert: 0 bei int, false bei boolean und null („nichts“) bei String. Besser ist es, jeden Startwert selbst festzulegen.
