Einfache Methoden

Methoden ohne Eingabe und ohne Rückgabe: Aufbau, Attributwerte ändern und Texte auf der Konsole ausgeben.

Was ist eine Methode?

Eine Methode beschreibt etwas, das jedes Objekt einer Klasse tun kann, zum Beispiel hupen oder 100 km fahren. Methoden stehen in der Klasse nach dem Konstruktor. Auf dieser Seite geht es um die einfachste Sorte: Methoden, die bei jedem Aufruf immer genau dasselbe tun. Man kann ihnen beim Aufruf nichts mitgeben, und sie liefern kein Ergebnis zurück.

Aufbau einer Methode

    public void fahre100km()
    {
        this.kilometerstand = this.kilometerstand + 100;
    }
TeilBedeutung
publicder Zugriffsmodifikator. Vorerst schreiben wir public vor jede Methode. Die Bedeutung lernst du später.
voidheißt „leer“: Die Methode liefert kein Ergebnis zurück.
fahre100kmder Name: beginnt klein, meist mit einem Verb
()runde Klammern; leer, weil man der Methode beim Aufruf nichts mitgibt
{ … }der Rumpf: die Anweisungen, die beim Aufruf ausgeführt werden. Jede Anweisung endet mit einem Semikolon.

Was eine einfache Methode tun kann

1. Einen Attributwert fest setzen. Das Attribut bekommt immer denselben neuen Wert:

    public void starteMotor()
    {
        this.motorLaeuft = true;
    }

2. Einen Attributwert verändern. Der neue Wert wird aus dem alten berechnet:

    public void fahre100km()
    {
        this.kilometerstand = this.kilometerstand + 100;
    }

Das liest man von rechts nach links: Nimm den bisherigen Kilometerstand, rechne 100 dazu und speichere das Ergebnis wieder im Attribut. Mit int-Werten kannst du auch - (minus) und * (mal) rechnen.

3. Einen Text auf der Konsole ausgeben.

    public void hupe()
    {
        System.out.println("Hup, hup!");
    }

System.out.println(…) schreibt, was in den Klammern steht, als eigene Zeile in das Konsolenfenster von BlueJ. Mit + verbindest du Texte und Attributwerte zu einer Ausgabe:

        System.out.println("Kilometerstand: " + this.kilometerstand + " km");

Bei einem Kilometerstand von 300 erscheint: Kilometerstand: 300 km.

Methoden aufrufen

In BlueJ rufst du eine Methode auf, indem du mit der rechten Maustaste auf ein Objekt in der Objektleiste klickst und die Methode auswählst. Sie wirkt nur auf dieses Objekt: Fährt auto1 100 km, ändert sich der Kilometerstand von auto2 nicht. Mit „Inspizieren“ siehst du die neuen Attributwerte.

Häufige Fehler

  • void vergessen: public hupe() ist falsch. Nur der Konstruktor hat kein void.
  • Klammern vergessen: Auch ohne Eingabe braucht der Name die runden Klammern ().
  • Semikolon nach der Kopfzeile: public void hupe(); gefolgt von { ist falsch.
  • Methode außerhalb der Klasse: Alle Methoden stehen innerhalb der äußeren geschweiften Klammern.
Ausblick: Später lernst du Methoden kennen, denen man beim Aufruf einen Wert mitgeben kann (z. B. „fahre 250 km“), und Methoden, die ein Ergebnis zurückliefern (z. B. den Kilometerstand).
