Verzweigungen

Bedingte Anweisungen mit if, else und else if

Mit bedingten Anweisungen reagiert ein Programm unterschiedlich auf verschiedene Situationen. Der Kern dieser Technik ist die if-Anweisung, die einen Codeblock nur dann ausführt, wenn eine Bedingung erfüllt ist. Bedingungen werden mit Vergleichsoperatoren formuliert – eine Einführung dazu findest du auf der Seite Vergleiche und Bedingungen.

Die if-Anweisung

Mit if wird eine Bedingung geprüft. Ist sie wahr (true), wird der Anweisungsblock in den geschweiften Klammern ausgeführt. Ist sie falsch (false), wird er übersprungen.

if (Bedingung) { // Anweisung(en) }

Beispiel: Das Programm soll eine Meldung ausgeben, wenn es heiß ist.

1int temperatur = 30;
2
3if (temperatur > 25) {
4 System.out.println("Es ist heiß.");
5}
6
7// Ausgabe: Es ist heiß.

Da temperatur den Wert 30 hat und 30 > 25 wahr ist, wird Zeile 4 ausgeführt. Hätte temperatur den Wert 20, wäre die Bedingung falsch – das Programm gäbe nichts aus.

Die if-else-Anweisung

Mit einem else-Block lässt sich eine Alternative angeben: Ist die Bedingung falsch, wird stattdessen der else-Block ausgeführt. Es wird immer genau einer der beiden Blöcke ausgeführt – nie beide, nie keiner.

if (Bedingung) { // wird ausgeführt, wenn Bedingung wahr ist } else { // wird ausgeführt, wenn Bedingung falsch ist }

Beispiel: Zugang zu einem System soll nur Erwachsenen gewährt werden.

1int alter = 16;
2
3if (alter >= 18) {
4 System.out.println("Zugang erlaubt.");
5} else {
6 System.out.println("Zugang verweigert.");
7}
8
9// Ausgabe: Zugang verweigert.

Da alter den Wert 16 hat, ist 16 >= 18 falsch. Das Programm führt daher den else-Block aus.

Mehrfache Fallunterscheidung mit else if

Sollen mehr als zwei Fälle unterschieden werden, können else if-Blöcke aneinandergereiht werden. Java prüft die Bedingungen der Reihe nach von oben nach unten. Sobald eine Bedingung zutrifft, wird der zugehörige Block ausgeführt – alle weiteren Bedingungen werden dann nicht mehr geprüft.

Beispiel: Notenvergabe anhand einer Punktzahl.

1int punkte = 82;
2String note;
3
4if (punkte >= 90) {
5 note = "sehr gut";
6} else if (punkte >= 75) {
7 note = "gut";
8} else if (punkte >= 60) {
9 note = "befriedigend";
10} else if (punkte >= 45) {
11 note = "ausreichend";
12} else {
13 note = "mangelhaft";
14}
15
16System.out.println("Deine Note: " + note);
17
18// Ausgabe: Deine Note: gut

Mit punkte = 82 ist die erste Bedingung (82 >= 90) falsch. Die zweite Bedingung (82 >= 75) ist wahr – also wird note = "gut" gesetzt und alle weiteren Blöcke werden übersprungen.

Der abschließende else-Block ist optional, fängt aber alle Fälle auf, die durch keine der vorherigen Bedingungen abgedeckt wurden – hier also alle Punktzahlen unter 45. Ohne ihn würde note in diesem Fall uninitialisiert bleiben, was zu einem Fehler führen kann.
