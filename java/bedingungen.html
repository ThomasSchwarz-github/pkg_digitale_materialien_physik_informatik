Vergleiche und Bedingungen

Wahrheitswerte, Vergleichsoperatoren und das Formulieren von Bedingungen

Bevor ein Programm Entscheidungen treffen kann, muss es Situationen vergleichen und bewerten können – zum Beispiel: Ist die Temperatur zu hoch? Hat der Nutzer genug Punkte? Diese Seite erklärt, wie Bedingungen in Java formuliert werden und welche Werkzeuge dafür zur Verfügung stehen.

Wahrheitswerte: true und false

In Java hat jeder Vergleich ein eindeutiges Ergebnis: Er ist entweder wahr oder falsch. Dafür gibt es in Java den Datentyp boolean mit genau zwei möglichen Werten: true (wahr) und false (falsch).

Eine boolean-Variable lässt sich direkt mit diesen Werten belegen:

1boolean istHeiß = true;
2boolean hatFehler = false;
3
4System.out.println(istHeiß); // Ausgabe: true
5System.out.println(hatFehler); // Ausgabe: false

In der Praxis werden boolean-Werte meist nicht direkt eingetragen, sondern durch einen Vergleich berechnet – zum Beispiel ob eine Zahl größer als eine andere ist.

Vergleichsoperatoren

Mit Vergleichsoperatoren werden zwei Werte verglichen. Das Ergebnis ist immer ein boolean-Wert – also true oder false.

Operator Bedeutung Beispiel
==gleichalter == 18
!=ungleichnote != 6
>größer alspunkte > 90
<kleiner alstemperatur < 0
>=größer oder gleichalter >= 18
<=kleiner oder gleichpunkte <= 49

Achtung: Für Vergleiche wird == (zwei Gleichheitszeichen) verwendet – nicht = (ein Gleichheitszeichen), das ist die Zuweisung und hat eine völlig andere Bedeutung.

Bedingungen auswerten – Beispiele

Ein Vergleich liefert direkt einen boolean-Wert. Das lässt sich mit System.out.println direkt ausgeben:

1int alter = 25;
2
3System.out.println(alter > 18); // Ausgabe: true
4System.out.println(alter == 30); // Ausgabe: false
5System.out.println(alter <= 25); // Ausgabe: true
6System.out.println(alter != 25); // Ausgabe: false

Das Ergebnis eines Vergleichs lässt sich auch in einer boolean-Variable speichern:

1int punkte = 73;
2boolean bestanden = (punkte >= 50); // true
3
4System.out.println(bestanden); // Ausgabe: true

Solche Bedingungen sind die Grundlage für alle Verzweigungen und Schleifen in Java – du wirst sie auf den nächsten Seiten direkt einsetzen.
