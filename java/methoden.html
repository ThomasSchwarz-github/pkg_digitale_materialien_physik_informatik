Methoden mit Parametern und Rückgabewerten

Methoden, die eine Antwort zurückgeben, Methoden, denen man Werte mitgibt, Getter, Setter und Konstruktoren mit Parametern.

Worum geht es?

In 03 Einfache Methoden hast du Methoden kennengelernt, die bei jedem Aufruf immer genau dasselbe tun und nichts zurückgeben. Methoden können aber noch mehr:

  • Sie können eine Antwort zurückgeben, den Rückgabewert.
  • Sie können beim Aufruf einen oder mehrere Werte mitbekommen, die Parameter.

Die Beispiele auf dieser Seite stammen aus einer Klasse Auto mit den Attributen farbe, tempo, maxTempo und motorAn.

Methoden mit Rückgabewert

    public int gibTempo()
    {
        return this.tempo;
    }
TeilBedeutung
intStatt void steht vor dem Namen der Datentyp der Antwort.
return this.tempo;gibt den Wert zurück. Danach ist die Methode sofort beendet.
  • Im Klassendiagramm steht der Datentyp der Antwort hinter der Methode: + gibTempo() : int.
  • In BlueJ erscheint die Antwort in einem kleinen Fenster, wenn du die Methode aufrufst.
  • Der zurückgegebene Wert muss zum Datentyp passen: Eine Methode mit boolean gibt true oder false zurück.
Getter: Methoden, die nur den Wert eines Attributs zurückgeben, heißen Getter. Ihr Name beginnt mit gib, bei Wahrheitswerten mit ist: gibFarbe(), gibTempo(), istMotorAn().

Methoden mit Parametern

    public void setzeMaxTempo(int pMaxTempo)
    {
        this.maxTempo = pMaxTempo;
    }
  • Der Parameter steht in den runden Klammern: erst sein Datentyp, dann sein Name. Wir beginnen Parameternamen mit p.
  • Beim Aufruf gibst du in BlueJ den Wert in ein Fenster ein. Dieser Wert steht dann während der Methode im Parameter.
  • Im Klassendiagramm steht der Parameter in der Form name : Datentyp: + setzeMaxTempo(pMaxTempo : int).
  • Mehrere Parameter werden durch Kommas getrennt: (String pFarbe, int pMaxTempo).
Setter: Methoden, die ein Attribut auf den übergebenen Wert setzen, heißen Setter. Ihr Name beginnt mit setze: setzeFarbe(String pFarbe).
Parameter oder Attribut? Der Parameter pMaxTempo existiert nur, solange die Methode läuft. Das Attribut maxTempo gehört zum Objekt und behält seinen Wert. Die Zeile this.maxTempo = pMaxTempo; speichert den Wert des Parameters dauerhaft im Attribut.

Beides zusammen

Eine Methode kann Parameter haben und einen Wert zurückgeben. Im Klassendiagramm steht dann beides:

    // + tempoNach(pSekunden : int) : int
    public int tempoNach(int pSekunden)
    {
        return this.tempo + 2 * pSekunden;
    }

Konstruktoren mit Parametern

Auch ein Konstruktor kann Parameter haben. So lassen sich Eigenschaften schon beim Herstellen eines Objekts festlegen:

    public Auto()
    {
        this.farbe = "rot";
        this.tempo = 0;
        this.maxTempo = 200;
        this.motorAn = false;
    }

    public Auto(String pFarbe, int pMaxTempo)
    {
        this.farbe = pFarbe;
        this.tempo = 0;
        this.maxTempo = pMaxTempo;
        this.motorAn = false;
    }
  • Eine Klasse darf mehrere Konstruktoren haben. Alle heißen wie die Klasse und unterscheiden sich nur in ihren Parametern.
  • Jeder Konstruktor gibt allen Attributen einen Startwert.
  • In BlueJ bietet der Rechtsklick auf die Klasse dann beide Konstruktoren an: new Auto() und new Auto(String pFarbe, int pMaxTempo).

Häufige Fehler

FehlerWas passiert?
return fehlt in einer Methode mit RückgabewertFehlermeldung „Rückgabeanweisung fehlt“ (missing return statement)
return in einer void-Methode mit WertFehlermeldung, denn eine void-Methode gibt nichts zurück
Datentyp beim Parameter vergessen: setzeMaxTempo(pMaxTempo)Fehlermeldung, denn im Kopf der Methode braucht jeder Parameter einen Datentyp
vertauscht: pMaxTempo = this.maxTempo;kein Fehler, aber das Attribut ändert sich nicht. Links vom = steht, was den neuen Wert bekommt.
