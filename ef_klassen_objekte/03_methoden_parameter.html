AB Aufgabe 1a

Die neue Klasse Auto hat vier Attribute: eine Farbe, das aktuelle Tempo in km/h, das Höchsttempo und ob der Motor an ist. So sieht ihr Klassendiagramm am Ende dieser Einheit aus. Grau gedruckt ist, was im Codegerüst noch fehlt:

  1. Lege in BlueJ ein neues Projekt AutoMitTempo mit einer Klasse Auto an.
  2. Öffne den Editor, lösche den vorgegebenen Inhalt und füge das Codegerüst ein.
  3. Übersetze die Klasse.
Codegerüst der Klasse Auto 
/**
 * Ein Auto mit Farbe, Tempo und Motor.
 * Codegerüst für Einheit (03): Diese Klasse ist noch unvollständig.
 */
public class Auto
{
    // Attribute
    private String farbe;
    private int tempo;
    private int maxTempo;
    private boolean motorAn;

    /**
     * Konstruktor: Ein neues Auto ist rot, steht still,
     * fährt höchstens 200 km/h und der Motor ist aus.
     */
    public Auto()
    {
        this.farbe = "rot";
        this.tempo = 0;
        this.maxTempo = 200;
        this.motorAn = false;
    }

    /**
     * Setzt die Farbe des Autos auf den übergebenen Wert.
     */
    public void setzeFarbe(String pFarbe)
    {
        this.farbe = pFarbe;
    }

    /**
     * Startet den Motor.
     */
    public void starteMotor()
    {
        this.motorAn = true;
    }

    /**
     * Erhöht das Tempo um den übergebenen Wert.
     */
    public void beschleunigeUm(int pTempo)
    {
        this.tempo = this.tempo + pTempo;
    }
}
Kommentare lesen! Über jeder Methode steht in einem Kommentar /** … */, was sie tut. Lies diese Kommentare, bevor du weiterarbeitest. Vieles kennst du schon: Attribute, Konstruktor und starteMotor().

Schritt 4 Methoden mit Parametern: Setter

AB Aufgabe 3

Bisher taten unsere Methoden bei jedem Aufruf immer genau dasselbe. Manche Methoden brauchen aber beim Aufruf einen Wert, z. B. die neue Farbe des Autos. Schau dir setzeFarbe an:

    public void setzeFarbe(String pFarbe)
    {
        this.farbe = pFarbe;
    }
  • In den runden Klammern steht der Parameter: erst sein Datentyp (String), dann sein Name (pFarbe). Den Namen beginnen wir mit p für „Parameter“.
  • Beim Aufruf gibst du in BlueJ den Wert ein, z. B. "blau". Dieser Wert steht dann in pFarbe.
  • this.farbe = pFarbe; speichert den übergebenen Wert im Attribut farbe.
  • Im Klassendiagramm steht der Parameter in der Form name : Datentyp in den Klammern: + setzeFarbe(pFarbe : String).

Methoden, die ein Attribut auf den übergebenen Wert setzen, heißen Setter (von engl. to set, setzen). Ihr Name beginnt mit setze.

Deine Aufgabe: Ergänze den Setter setzeMaxTempo(int pMaxTempo) direkt unter setzeFarbe. Übersetze und teste ihn. Inspiziere das Auto vor und nach dem Aufruf.

Hilfe: Was ist anders als bei setzeFarbe?

Drei Dinge: der Name der Methode, der Parameter (Datentyp int, Name pMaxTempo) und das Attribut, in dem der Wert gespeichert wird (maxTempo).

⚠️ Fehlermeldung beim Aufruf in BlueJ? Für einen int-Parameter gibst du eine Zahl ohne Anführungszeichen ein, für einen String-Parameter einen Text mit Anführungszeichen.

Mit Parametern rechnen

Schritt 5 Bremsen: bremseUm selbst schreiben

AB Aufgabe 4

Nicht jede Methode mit Parameter ist ein Setter. Schau dir beschleunigeUm an:

    /**
     * Erhöht das Tempo um den übergebenen Wert.
     */
    public void beschleunigeUm(int pTempo)
    {
        this.tempo = this.tempo + pTempo;
    }
  • beschleunigeUm setzt das Tempo nicht auf den übergebenen Wert, sondern verändert den bisherigen Wert: Das neue Tempo ist das alte Tempo plus der Parameter.
  • Rechts vom = wird zuerst gerechnet, dann wird das Ergebnis links im Attribut gespeichert. Bei Tempo 30 und beschleunigeUm(50) wird also 30 + 50 = 80 gerechnet und gespeichert.

Deine Aufgabe: Dein Auto kann schon beschleunigen, aber noch nicht bremsen. Ergänze die Methode bremseUm(int pTempo) direkt unter beschleunigeUm. Sie verringert das Tempo um den übergebenen Wert. Schreibe auch einen Kommentar darüber, was sie tut.

Teste: Starte den Motor, beschleunige um 80, bremse um 30 und inspiziere das Auto. Welches Tempo erwartest du? Bremse danach um mehr, als das Auto gerade fährt.

Hilfe 1: Was muss ich ändern?

Kopiere beschleunigeUm und ändere genau zwei Dinge: den Namen der Methode und das Rechenzeichen.

Hilfe 2: Wie wird ein Wert verringert?

Genau wie beim Erhöhen, nur mit Minus: Der neue Wert ist der alte Wert minus den Parameter.

Kommt dir das merkwürdig vor? Das ist richtig so: Heute darf deine Methode das noch. Wie man ein Auto vor solchen Werten schützt, lernst du in Einheit (05).
Schritt 6 Zusammenfassen

Vergleiche deine fertige Klasse mit dem Klassendiagramm aus Schritt 1. Fehlt noch etwas? Überprüfe dich danach mit der Zusammenfassung.

Zusammenfassung anzeigen

Parameter: ein Wert, den man der Methode beim Aufruf mitgibt. Er steht mit Datentyp und Namen in den runden Klammern, z. B. (int pTempo). Im Klassendiagramm: + beschleunigeUm(pTempo : int).

Parameter oder Attribut? Der Parameter gilt nur, solange die Methode läuft. Das Attribut gehört zum Objekt und behält seinen Wert dauerhaft.

Setter: setzt ein Attribut auf den übergebenen Wert, z. B. this.maxTempo = pMaxTempo;

Mit Parametern rechnen: Andere Methoden verändern den bisherigen Wert, z. B. this.tempo = this.tempo - pTempo;

Zusatz Für Schnelle: ein zweiter Konstruktor

Bisher ist jedes neue Auto rot und fährt höchstens 200 km/h. Schöner wäre es, Farbe und Höchsttempo schon beim Herstellen festzulegen. Dafür bekommt die Klasse einen zweiten Konstruktor mit Parametern: Auto(String pFarbe, int pMaxTempo).

  • Eine Klasse darf mehrere Konstruktoren haben. Alle heißen genau wie die Klasse und unterscheiden sich nur in ihren Parametern.
  • Mehrere Parameter werden durch Kommas getrennt.
  • Auch der neue Konstruktor muss allen Attributen einen Startwert geben. Ein neues Auto steht still (Tempo 0), und der Motor ist aus.

Ergänze den Konstruktor direkt unter dem ersten. Beim Rechtsklick auf die Klasse bietet BlueJ dir dann zwei Möglichkeiten an, ein Auto herzustellen. Erzeuge mit beiden je ein Auto und inspiziere sie.

Hilfe: So beginnt der Konstruktor 
    public Auto(String pFarbe, int pMaxTempo)
    {
        this.farbe = pFarbe;
        // Ergänze hier die Startwerte für die anderen drei Attribute.
    }

Hinweis: Die Zwischenlösung für Einheit (04) enthält den zweiten Konstruktor nicht. Wenn du ihn behalten möchtest, kopiere ihn später in dein neues Projekt.
