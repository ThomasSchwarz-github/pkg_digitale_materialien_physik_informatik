/**
 * Ein Auto mit Farbe, Tempo und Motor.
 * Zwischenlösung für Einheit (04): die Lösung aus Einheit (03).
 */
public class Auto
{
    // Attribute
    private String farbe;
    private int tempo;
    private int maxTempo;
    private boolean motorAn;

    /**
     * Konstruktor: Ein neues Auto ist rot, steht still,
     * fährt höchstens 200 km/h und der Motor ist aus.
     */
    public Auto()
    {
        this.farbe = "rot";
        this.tempo = 0;
        this.maxTempo = 200;
        this.motorAn = false;
    }

    /**
     * Setzt die Farbe des Autos auf den übergebenen Wert.
     */
    public void setzeFarbe(String pFarbe)
    {
        this.farbe = pFarbe;
    }

    /**
     * Setzt das Höchsttempo auf den übergebenen Wert.
     */
    public void setzeMaxTempo(int pMaxTempo)
    {
        this.maxTempo = pMaxTempo;
    }

    /**
     * Startet den Motor.
     */
    public void starteMotor()
    {
        this.motorAn = true;
    }

    /**
     * Stoppt den Motor.
     */
    public void stoppeMotor()
    {
        this.motorAn = false;
    }

    /**
     * Erhöht das Tempo um den übergebenen Wert.
     */
    public void beschleunigeUm(int pTempo)
    {
        this.tempo = this.tempo + pTempo;
    }

    /**
     * Verringert das Tempo um den übergebenen Wert.
     */
    public void bremseUm(int pTempo)
    {
        this.tempo = this.tempo - pTempo;
    }
}
Schritt 2 Attributwerte abfragen: der erste Getter

AB Aufgabe 1b

Den Zustand eines Objekts, also seine Attributwerte, konntest du bisher nur mit dem Inspektor ansehen. Der Inspektor ist aber nur ein Hilfsmittel, das in die Entwicklungsumgebung BlueJ für Lernende eingebaut ist. Ein Programm selbst kann ihn nicht benutzen, zum Beispiel um das Tempo auf einem Tacho anzuzeigen. Auch direkt auf die Attribute können andere Programmteile nicht zugreifen, denn sie sind private.

In der objektorientierten Programmierung schreibt man deshalb eigene Methoden, die den Wert eines Attributs zurückgeben. Sie heißen Getter:

    /**
     * Gibt das aktuelle Tempo zurück.
     */
    public int gibTempo()
    {
        return this.tempo;
    }
Was?Wo?Bedeutung
DatentypZeile 4: intDatentyp des Rückgabewerts. Er steht an der Stelle, an der bisher void stand. void („leer“) bedeutet: Es wird nichts zurückgegeben.
NameZeile 4: gibTempo()gib und der Name des Attributs. Die Klammern sind leer, denn der Getter braucht keinen Parameter.
returnZeile 6: returngibt den Wert zurück, der dahinter steht, und beendet die Methode.
RückgabewertZeile 6: this.tempoder aktuelle Wert des Attributs tempo. Er muss zum Datentyp in Zeile 4 passen.
Klassendiagramm+ gibTempo() : intDer Datentyp des Rückgabewerts steht hinter den Klammern.

Deine Aufgabe: Ergänze gibTempo() direkt unter dem Konstruktor und übersetze. Erzeuge ein Auto, beschleunige es um 50 und rufe gibTempo() auf. BlueJ zeigt den Rückgabewert 50 in einem kleinen Fenster an.

Getter und Setter: Die Namen kommen aus dem Englischen. Dort beginnen solche Methoden mit get (bekommen) und set (setzen), z. B. getTempo() und setTempo(…). In unserem Kurs verwenden wir deutsche Namen: gib… und setze…, bei Wahrheitswerten (boolean) ist… statt gib…. Dahinter folgt immer der Name des Attributs: gibTempo(), setzeFarbe(…), istMotorAn().

Schritt 4 Rechnen und das Ergebnis zurückgeben

AB Aufgabe 3

Hinter return muss nicht ein Attribut allein stehen, es kann auch eine Rechnung sein. Ein Beispiel ist eine Faustformel aus der Fahrschule: Der Reaktionsweg (die Strecke, die ein Auto fährt, bis man auf die Bremse tritt) ist in Metern ungefähr das Tempo geteilt durch 10, mal 3.

    /**
     * Gibt den Reaktionsweg in Metern zurück (Faustformel).
     */
    public int berechneReaktionsweg()
    {
        return this.tempo * 3 / 10;
    }

Das passiert beim Aufruf, wenn das Auto 50 km/h fährt:

  1. this.tempo wird durch den Attributwert ersetzt: 50 * 3 / 10
  2. Die Rechnung wird von links nach rechts ausgewertet: 150 / 10, also 15
  3. return gibt das Ergebnis 15 zurück.

Die Attribute ändern sich dabei nicht: Das Auto fährt danach immer noch 50 km/h. Solche Methoden sind keine Getter, weil sie nicht einfach den Wert eines Attributs zurückgeben. Ihr Name beginnt bei uns oft mit berechne.

ZeichenBedeutungBeispiel mit ganzen Zahlen
+ und -plus und minus55 - 10 ergibt 45
*mal55 * 3 ergibt 165
/geteilt; die Nachkommastellen fallen weg165 / 10 ergibt 16 (nicht 16,5)
⚠️ Reihenfolge beim Teilen: Bei 55 km/h ergibt 55 * 3 / 10 den Wert 16. Mit 55 / 10 * 3 würde zuerst auf 5 abgeschnitten, und es käme nur 15 heraus. Multipliziere deshalb zuerst und teile danach. Punktrechnung geht auch in Java vor Strichrechnung, Klammern kannst du wie in Mathe setzen.

Deine Aufgabe: Programmiere + berechneTempoReserve() : int. Die Methode gibt zurück, um wie viel km/h das Auto noch bis zum Höchsttempo beschleunigen kann.

Teste mindestens diese Fälle: Ein neues Auto hat die Reserve 200. Nach beschleunigeUm(80) ist sie 120. Nach setzeMaxTempo(100) ist sie 20.

Hilfe 1: Was muss berechnet werden?

Bei Höchsttempo 200 und Tempo 80 ist die Reserve 200 − 80. Welche beiden Attribute stecken hinter den Zahlen?

Hilfe 2: Der Aufbau 
    public int berechneTempoReserve()
    {
        return  // Höchsttempo minus Tempo
    }
Lösung zum Vergleichen 
    /**
     * Gibt zurück, um wie viel km/h das Auto noch beschleunigen kann.
     */
    public int berechneTempoReserve()
    {
        return this.maxTempo - this.tempo;
    }
Schritt 5 Der Anhalteweg

AB Aufgabe 4

Bis ein Auto steht, vergehen zwei Strecken: der Reaktionsweg und danach der Bremsweg. Beide zusammen ergeben den Anhalteweg. Die Faustformeln (Tempo in km/h, Ergebnis in Metern):

  • Reaktionsweg = (Tempo : 10) · 3
  • Bremsweg = (Tempo : 10) · (Tempo : 10)
  • Anhalteweg = Reaktionsweg + Bremsweg

Deine Aufgabe:

  1. Übernimm berechneReaktionsweg() aus Schritt 4. Programmiere danach + berechneBremsweg() : int.
  2. Programmiere + berechneAnhalteweg() : int und benutze dafür die beiden anderen Methoden.
  3. Berechne die Werte in der Tabelle von Hand und prüfe sie hier. Teste danach deine Methoden mit den drei Tempowerten.
Methoden des eigenen Objekts aufrufen: Mit this kann ein Objekt seine eigenen Methoden aufrufen. this.berechneReaktionsweg() wird beim Ausführen durch den Rückgabewert der Methode ersetzt. Mit diesem Wert kann man weiterrechnen, genau wie mit einem Attributwert.

Hilfe 1: Der Bremsweg

(Tempo : 10) · (Tempo : 10) ist dasselbe wie Tempo · Tempo : 100. Die zweite Form ist beim Rechnen mit ganzen Zahlen genauer, weil zuerst multipliziert und dann geteilt wird.

Hilfe 2: Der Anhalteweg

Hinter return steht eine Summe aus zwei Methodenaufrufen. Der erste Summand ist this.berechneReaktionsweg().

Lösung zum Vergleichen 
    /**
     * Gibt den Bremsweg in Metern zurück (Faustformel).
     */
    public int berechneBremsweg()
    {
        return this.tempo * this.tempo / 100;
    }

    /**
     * Gibt den Anhalteweg in Metern zurück: Reaktionsweg und Bremsweg zusammen.
     */
    public int berechneAnhalteweg()
    {
        return this.berechneReaktionsweg() + this.berechneBremsweg();
    }
Schritt 6 Parameter und Rückgabewert in einer Methode

AB Aufgabe 5

Eine Methode kann einen Parameter haben und einen Wert zurückgeben. Im Klassendiagramm steht dann beides, zum Beispiel + berechneTempoNach(pTempo : int) : int:

  • in den Klammern der Parameter: ein Wert, den die Methode beim Aufruf mitbekommt,
  • hinter den Klammern der Datentyp des Rückgabewerts, den die Methode liefert.

Aufgabe a): Programmiere + berechneTempoNach(pTempo : int) : int. Die Methode gibt zurück, welches Tempo das Auto hätte, wenn es um pTempo schneller wäre, ohne es wirklich zu beschleunigen. Teste: Beschleunige ein Auto um 80. berechneTempoNach(30) liefert 110, und der Inspektor zeigt danach immer noch Tempo 80.

Hilfe zu a): Was ist anders als bei beschleunigeUm?

beschleunigeUm speichert das Ergebnis im Attribut (this.tempo = …). Hier soll das Attribut unverändert bleiben. Die Rechnung steht deshalb direkt hinter return, ohne Zuweisung.

Lösung zu a) zum Vergleichen 
    /**
     * Gibt zurück, welches Tempo das Auto hätte, wenn es um den übergebenen
     * Wert schneller wäre. Das Tempo selbst ändert sich dabei nicht.
     */
    public int berechneTempoNach(int pTempo)
    {
        return this.tempo + pTempo;
    }

Aufgabe b): Programmiere + erstelleBeschreibung() : String. Der Rückgabewert ist ein Text, der zum aktuellen Zustand passt, z. B. "Farbe: rot, Tempo: 50 km/h". Texte und Attributwerte verbindest du mit +, wie bei System.out.println. Achte auf die Leerzeichen.

Hilfe zu b): Der Anfang

return "Farbe: " + this.farbe + …

Lösung zu b) zum Vergleichen 
    /**
     * Gibt einen Text zurück, der das Auto beschreibt.
     */
    public String erstelleBeschreibung()
    {
        return "Farbe: " + this.farbe + ", Tempo: " + this.tempo + " km/h";
    }
Ausgeben oder zurückgeben? System.out.println(…) schreibt einen Text in das Konsolenfenster. Er ist dann nur zu lesen, das Programm kann ihn nicht weiterverwenden. return gibt einen Wert an die Stelle zurück, an der die Methode aufgerufen wurde. Dort kann man mit ihm weiterarbeiten, so wie berechneAnhalteweg() mit den Rückgabewerten der anderen beiden Methoden.
Schritt 7 Zusammenfassen und üben

Vergleiche deine fertige Klasse mit dem Klassendiagramm aus Schritt 1. Den Merksatz auf dem Arbeitsblatt füllen wir am Ende der Stunde gemeinsam aus.

Zusammenfassung anzeigen

Rückgabewert: der Wert, den eine Methode beim Aufruf liefert. Statt void steht sein Datentyp vor dem Methodennamen, mit return wird er zurückgegeben. Im Klassendiagramm steht der Datentyp hinter den Klammern: + gibTempo() : int.

Getter: geben den Wert eines Attributs zurück. Name: gib (bei Wahrheitswerten ist) und der Attributname.

Andere Methoden mit Rückgabewert: berechnen ihren Rückgabewert, z. B. return this.maxTempo - this.tempo;. Sie können auch Parameter haben.

Zusatz 1 Strecke und Fahrzeit
  1. Programmiere + berechneStrecke(pMinuten : int) : int. Die Methode gibt zurück, wie viele Kilometer das Auto mit dem aktuellen Tempo in der angegebenen Zeit fährt. Test: Bei Tempo 80 sind es in 45 Minuten 60 km.
  2. Programmiere + berechneFahrzeit(pKilometer : int) : int. Die Methode gibt zurück, wie viele Minuten das Auto mit dem aktuellen Tempo für die Strecke braucht. Test: Bei Tempo 80 dauern 120 km 90 Minuten.
  3. Rufe berechneFahrzeit(100) bei einem stehenden Auto auf und erkläre die Fehlermeldung. Wie man so etwas verhindert, lernst du in Einheit (05).
Hilfe: Die Formeln

80 km/h bedeutet: 80 km in 60 Minuten. In einer Minute sind es 80 : 60 km. Multipliziere auch hier zuerst und teile danach.

Lösung zum Vergleichen 
    public int berechneStrecke(int pMinuten)
    {
        return this.tempo * pMinuten / 60;
    }

    public int berechneFahrzeit(int pKilometer)
    {
        return pKilometer * 60 / this.tempo;
    }

Bei einem stehenden Auto ist tempo gleich 0. Durch 0 kann man nicht teilen, deshalb bricht die Methode mit ArithmeticException: / by zero ab.

Zusatz 2 Vergleiche zurückgeben

Ein Vergleich hat selbst einen Wert: true, wenn er stimmt, sonst false. Deshalb kann er hinter return stehen. Der Datentyp des Rückgabewerts ist dann boolean.

ZeichenBedeutungBeispiel
< und <=kleiner; kleiner oder gleich30 < 50 ist true
> und >=größer; größer oder gleich30 >= 50 ist false
==gleich (zwei Gleichheitszeichen)50 == 50 ist true
  1. Programmiere + istSchnellerAls(pTempo : int) : boolean. Test: Bei Tempo 80 liefert istSchnellerAls(50) den Wert true, istSchnellerAls(80) aber false.
  2. Programmiere + istAmLimit() : boolean. Die Methode gibt zurück, ob das Auto genau mit Höchsttempo fährt.
Lösung zum Vergleichen 
    public boolean istSchnellerAls(int pTempo)
    {
        return this.tempo > pTempo;
    }

    public boolean istAmLimit()
    {
        return this.tempo == this.maxTempo;
    }

Hilfe: Womit fange ich an?

Gehe in dieser Reihenfolge vor und übersetze nach jedem Schritt: Attribute, Konstruktor, Getter, Setter, dann die Methoden mit Rechnung. Schau dir bei Unsicherheit die Klasse Auto an.

public class Rechteck
{
    private int breite;
    private int hoehe;

    public Rechteck()
    {
        this.breite = 4;
        this.hoehe = 3;
    }

    public int gibBreite()
    {
        return this.breite;
    }

    public int gibHoehe()
    {
        return this.hoehe;
    }

    public void setzeBreite(int pBreite)
    {
        this.breite = pBreite;
    }

    public void setzeHoehe(int pHoehe)
    {
        this.hoehe = pHoehe;
    }

    public int berechneFlaeche()
    {
        return this.breite * this.hoehe;
    }

    public int berechneUmfang()
    {
        return 2 * this.breite + 2 * this.hoehe;
    }

    public boolean istQuadrat()
    {
        return this.breite == this.hoehe;
    }

    public int berechneFlaecheBeiBreiteUm(int pZentimeter)
    {
        return (this.breite + pZentimeter) * this.hoehe;
    }

    public String erstelleBeschreibung()
    {
        return this.breite + " cm x " + this.hoehe + " cm";
    }
}
