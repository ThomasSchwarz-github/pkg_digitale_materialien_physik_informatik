Schritt 1 Rückblick: Klasse, Objekt, Attribut und Methode

AB Infokasten oben

In der letzten Einheit hast du die Klasse Auto kennengelernt und drei Objekte auto1, auto2 und auto3 vom Typ Auto erzeugt. Damit hast du die objektorientierte Programmierung kennengelernt.

Was ist objektorientierte Programmierung?

Ein Programm verarbeitet Daten (z. B. Kilometerstände oder Namen) mit Funktionen, die etwas mit diesen Daten tun (z. B. „fahre 100 km“). In der objektorientierten Programmierung werden Daten und die Funktionen, die mit ihnen arbeiten, zu Objekten zusammengefasst. Ein Objekt ist so etwas wie ein Ding aus der wirklichen Welt im Computer: Ein Auto-Objekt weiß seinen Kilometerstand und kann selbst 100 km fahren.

Für jede Sorte von Objekten gibt es einen gemeinsamen Bauplan, die Klasse. Sie beschreibt einmal, welche Daten (Attribute) und welche Funktionen (Methoden) alle Objekte dieser Sorte haben. Danach kann man beliebig viele Objekte nach diesem Bauplan herstellen.

Warum macht man das? Große Programme bestehen aus Tausenden Zeilen Code. Wenn Daten und die passenden Funktionen zusammen in einem Objekt stecken, bleibt das Programm übersichtlich: Alles, was ein Auto betrifft, steht in der Klasse Auto. Außerdem lässt sich ein Bauplan immer wieder verwenden. Java, mit dem wir arbeiten, ist eine objektorientierte Programmiersprache, ebenso wie z. B. Python oder C#.

Jetzt schauen wir genauer hin, was im Bauplan Auto stand. Er legt zwei Dinge fest:

  • Attribute sind die Eigenschaften, die sich jedes Objekt merkt. Deine Autos hatten die Attribute name und gefahreneStrecke.
  • Methoden sind die Dinge, die jedes Objekt tun kann. Deine Autos konnten hupe(), fahre100km() und zeigeGefahreneStreckeAn().

Merke: Die Klasse legt fest, welche Attribute und Methoden es gibt. Jedes Objekt hat für die Attribute seine eigenen Werte, die Attributwerte. Beide Autos haben eine gefahrene Strecke, aber jedes eine andere.
💡 Gute Namen für Attribute. In der letzten Einheit hast du im Attribut name Texte wie "Porsche" gespeichert. Für einen ersten Einstieg war das in Ordnung, genau genommen passt der Name aber nicht zum Inhalt:
  • „Name“ klingt nach dem Namen, den eine Person ihrem Auto gibt (z. B. „Flitzer“), oder nach dem Namen, unter dem ein Auto im Programm angesprochen wird (z. B. auto1).
  • "Porsche" ist aber die Marke des Autos. Passender wäre deshalb ein Attribut marke mit dem Wert "Porsche". Soll auch das Modell gespeichert werden, kommt ein zweites Attribut dazu, z. B. modell mit dem Wert "911 Carrera".
Benenne Attribute immer so, dass man am Namen sofort erkennt, was darin gespeichert ist. Das hilft dir und allen, die dein Programm später lesen.
Erinnerst du dich? Im Inspektor stand private String name und private int gefahreneStrecke. Die Wörter String und int sind Datentypen. Was das bedeutet, erfährst du in Schritt 3.

Schritt 3 Datentypen: int, String und boolean

AB Aufgabe 2

⚠️ Aufgepasst:
  • Ein Kennzeichen enthält Ziffern, ist aber trotzdem Text: String.
  • int kann keine Kommazahlen speichern. Rechne für heute mit ganzen Litern oder Euro.
  • Eine Frage wie „Läuft der Motor?“ wird zum Attributnamen motorLaeuft, nicht zu "ja" oder "nein".

Regeln für Attributnamen: Sie beginnen mit einem Kleinbuchstaben und enthalten keine Leerzeichen und keine Umlaute. Bei mehreren Wörtern beginnt jedes weitere Wort groß: kilometerstand, motorLaeuft, anzahlTueren.

Schritt 4 Methoden für den Anfang

AB Aufgabe 3

Methoden beschreiben, was ein Objekt tun kann. Unsere ersten Methoden tun bei jedem Aufruf immer genau dasselbe. Du kannst ihnen beim Aufruf nichts mitgeben. (Erinnerst du dich? Beim Herstellen der Autos in der letzten Einheit musstest du einen Namen eingeben. So etwas gibt es bei unseren Methoden noch nicht.) Eine solche Methode tut eines von zwei Dingen:

  1. Einen Attributwert immer auf dieselbe Weise ändern. Beispiele: starteMotor() setzt motorLaeuft auf true, stoppeMotor() setzt es auf false, fahre100km() erhöht den Kilometerstand bei jedem Aufruf um genau 100.
  2. Immer denselben Text auf der Konsole ausgeben. Beispiel: hupe() gibt „Hup, hup!“ aus.

Methodennamen beginnen klein, meist mit einem Verb, und enden mit runden Klammern ().

Was geht heute noch nicht? (kommt später)

Eine Methode „fahre so weit, wie ich eingebe“ oder „tanke so viel, wie ich sage“ müsste beim Aufruf eine Zahl von dir bekommen. Eine Methode „Wie hoch ist der Kilometerstand?“ müsste dir eine Antwort zurückgeben. Beides lernst du in den nächsten Einheiten. Wähle heute Methoden, die immer dasselbe tun, z. B. fahre100km() statt „fahre x km“.

Schritt 5 Das Klassendiagramm

AB Aufgabe 3

Ein Klassendiagramm zeigt den Bauplan einer Klasse auf einen Blick. Informatikerinnen und Informatiker auf der ganzen Welt verwenden dafür dieselbe Darstellung. Es hat drei Teile:

Lampe
- farbe : String
- helligkeit : int
- istAn : boolean
+ schalteEin()
+ werdeHeller()
+ zeigeZustand()
  • oben der Name der Klasse (groß geschrieben),
  • in der Mitte die Attribute: - name : Datentyp,
  • unten die Methoden: + name().
Was bedeuten − und +? Das Minus steht für private: Nur das Objekt selbst darf seine Attribute verändern, niemand von außen. Das Plus steht für public: Die Methode darf von außen aufgerufen werden, z. B. von dir per Rechtsklick in BlueJ.
⚠️ Häufige Fehler im Diagramm: Datentyp vergessen, Attribut groß geschrieben, Klammern () bei Methoden vergessen, Leerzeichen im Namen.
Schritt 6 Die Klasse Auto in BlueJ umsetzen

AB Aufgabe 4

Jetzt wird aus deinem Klassendiagramm Java-Code. Gehe Zeile für Zeile durch dein Diagramm. Das Beispiel zeigt jeweils die Klasse Lampe, du schreibst den Code für deine Klasse Auto.

a) Projekt und Klasse anlegen. Lege ein neues Projekt Bordcomputer an und darin eine Klasse Auto (wie in Einheit 01). Öffne den Editor und lösche alles bis auf den Klassenrahmen. Übrig bleibt:

public class Auto
{

}

Alles Weitere schreibst du zwischen die beiden geschweiften Klammern.

b) Attribute. Aus jeder Attributzeile im Diagramm wird eine Zeile Code. Das - wird zu private, danach folgen erst der Datentyp, dann der Name und ein Semikolon.

Muster: aus „- name : Datentyp“ wird …
    private Datentyp name;
Beispiel Lampe
    private String farbe;
    private int helligkeit;
    private boolean istAn;

c) Konstruktor mit Startwerten. Der Konstruktor heißt genau wie die Klasse. Er legt fest, welche Werte ein neues Objekt am Anfang hat. Gib jedem Attribut einen Startwert, der zu seinem Datentyp passt.

Beispiel Lampe
    public Lampe()
    {
        this.farbe = "gelb";
        this.helligkeit = 0;
        this.istAn = false;
    }
Warum Startwerte? Ohne Startwert hätte eine Zahl den Wert 0, ein Wahrheitswert false und ein Text den Wert null („nichts“). Mit eigenen Startwerten bestimmst du selbst, wie ein neues Auto aussieht. this.farbe bedeutet: die Farbe dieses Objekts.

d) Methoden. Aus + name() wird public void name(), gefolgt von geschweiften Klammern mit dem, was die Methode tut.

Beispiel Lampe: Art (1), einen Attributwert ändern
    public void schalteEin()
    {
        this.istAn = true;
    }

    public void werdeHeller()
    {
        this.helligkeit = this.helligkeit + 10;
    }
Beispiel Lampe: Art (2), etwas auf der Konsole ausgeben
    public void zeigeZustand()
    {
        System.out.println("Die Lampe ist " + this.farbe + ", Helligkeit: " + this.helligkeit);
    }
Was bedeutet das? void heißt „leer“: Die Methode liefert kein Ergebnis zurück. Die leeren Klammern () zeigen, dass sie keine Eingabe braucht. this.helligkeit = this.helligkeit + 10; bedeutet: Nimm den bisherigen Wert, rechne 10 dazu und speichere das Ergebnis wieder im Attribut. Mit + kann man auch Texte und Werte zu einer Ausgabe zusammensetzen.
Die ganze Beispielklasse Lampe zum Ausprobieren

Du kannst die Klasse Lampe auch selbst in BlueJ anlegen und testen, um zu sehen, wie alles zusammenspielt.

/**
 * Eine Lampe, die man einschalten und heller machen kann.
 */
public class Lampe
{
    private String farbe;
    private int helligkeit;
    private boolean istAn;

    public Lampe()
    {
        this.farbe = "gelb";
        this.helligkeit = 0;
        this.istAn = false;
    }

    public void schalteEin()
    {
        this.istAn = true;
    }

    public void werdeHeller()
    {
        this.helligkeit = this.helligkeit + 10;
    }

    public void zeigeZustand()
    {
        System.out.println("Die Lampe ist " + this.farbe + ", Helligkeit: " + this.helligkeit);
    }
}

So könnte eine Klasse Auto aussehen. Deine darf andere Attribute und Methoden haben.

Auto
- marke : String
- kilometerstand : int
- motorLaeuft : boolean
+ starteMotor()
+ fahre100km()
+ hupe()
public class Auto
{
    private String marke;
    private int kilometerstand;
    private boolean motorLaeuft;

    public Auto()
    {
        this.marke = "VW";
        this.kilometerstand = 0;
        this.motorLaeuft = false;
    }

    public void starteMotor()
    {
        this.motorLaeuft = true;
    }

    public void fahre100km()
    {
        this.kilometerstand = this.kilometerstand + 100;
    }

    public void hupe()
    {
        System.out.println(this.marke + ": Hup, hup!");
    }
}
Schritt 7 Zusammenfassen

Erkläre mit eigenen Worten, was die Begriffe dieser Einheit bedeuten. Überprüfe dich danach mit der Zusammenfassung.

Zusammenfassung anzeigen

Klasse: Bauplan für Objekte. Sie legt die Attribute und Methoden fest.

Objekt (Instanz): ein nach dem Bauplan hergestelltes Exemplar mit eigenen Attributwerten.

Attribut: eine Eigenschaft, die sich jedes Objekt merkt, mit Namen und Datentyp (int, String oder boolean).

Attributwert: der Wert, den ein bestimmtes Objekt gerade für ein Attribut gespeichert hat.

Methode: etwas, das jedes Objekt tun kann. Heute: einen Attributwert ändern oder etwas ausgeben.

Klassendiagramm: Name, Attribute (- name : Datentyp), Methoden (+ name()).

Zusatz Für Schnelle
  1. Ergänze ein viertes Attribut, z. B. tankinhalt : int (in Litern), mit einem passenden Startwert.

  3. Schreibe eine Methode zeigeKilometerstand(), die zum Beispiel „Kilometerstand: 300 km“ auf der Konsole ausgibt. Orientiere dich an zeigeZustand() der Lampe.
  4. Ergänze dein Klassendiagramm auf dem Arbeitsblatt um die neuen Attribute und Methoden.
